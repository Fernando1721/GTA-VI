# 🎮 GTA VI — Experiência Interativa com IA

Projeto web inspirado no universo de GTA VI, desenvolvido com HTML, CSS e JavaScript, com uma funcionalidade que utiliza Inteligência Artificial para transformar a foto do usuário em um personagem inspirado no estilo visual do jogo.

## 🚀 Funcionalidades

* 🎭 **Personagens:** opções interativas para Lucia, Jason e CJ.
* 🤖 **Inteligência Artificial:** permite enviar uma foto para transformá-la em um personagem inspirado no universo GTA.
* 👤 **Modo VOCÊ:** exibe a imagem gerada pela IA na tela, identificando o personagem como "VOCÊ".
* 🎨 **Interface interativa:** experiência visual inspirada no universo de GTA VI.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Inteligência Artificial para geração e transformação de imagens

## 💻 Como executar o projeto

1. Clone este repositório:

   ```bash
   git clone https://github.com/Fernando1721/GTA-VI.git
   ```

2. Entre na pasta do projeto.

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no Visual Studio Code.

4. Explore os personagens e teste a funcionalidade **VOCÊ**.

> **Observação:** a funcionalidade de Inteligência Artificial pode depender de uma conexão com um serviço externo e de sua configuração para funcionar corretamente.

## 🎯 Objetivo do projeto

Praticar e aprimorar conhecimentos em desenvolvimento web, interatividade com JavaScript e integração com ferramentas de Inteligência Artificial.
